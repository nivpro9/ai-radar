# רדאר AI

אתר חדשות וכלי בינה מלאכותית בעברית. החדשות נסרקות אוטומטית כל שעה.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | האתר עצמו |
| `data/content.json` | כלים, טיפים, פרומפטים, תוספים וקוד (עורכים ידנית) |
| `data/news.json` | החדשות (מתעדכן לבד כל שעה) |
| `scripts/feeds.json` | רשימת המקורות שנסרקים. אפשר להוסיף ולהוריד |
| `scripts/fetch_news.py` | הסורק |
| `.github/workflows/update-news.yml` | ההוראה ל־GitHub להריץ את הסורק כל שעה |

## העלאה לאוויר (פעם אחת, כ־10 דקות)

### דרך א': עם Claude Code (הכי קל)
1. פתח את Claude Code (באפליקציית Claude לדסקטופ, לשונית Code, או בטרמינל).
2. חלץ את קובץ ה־zip לתיקייה ופתח אותה ב־Claude Code.
3. כתוב לו: **"צור ריפו חדש בגיטהאב בשם ai-radar, העלה את כל הקבצים והפעל GitHub Pages מענף main"**.
   בפעם הראשונה הוא יבקש ממך להתחבר ל־GitHub. אתה מאשר בדפדפן, והוא לא רואה את הסיסמה שלך.
4. המשך לשלב "מפתח ה־API" למטה.

### דרך ב': ידנית באתר של GitHub
1. היכנס ל־github.com ← **New repository** ← שם: `ai-radar` ← **Public** ← Create.
2. בעמוד הריפו: **Add file ← Upload files**, וגרור את כל הקבצים והתיקיות.
   שים לב: התיקייה `.github` מוסתרת במחשב. אם היא לא עלתה, צור קובץ חדש בשם
   `.github/workflows/update-news.yml` והדבק לתוכו את התוכן שלו.
3. **Settings ← Pages ← Source: Deploy from a branch ← main ← / (root) ← Save.**
   אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/ai-radar`.

### מפתח ה־API (לא חובה, אבל מומלץ)
בלי מפתח, הסורק עובד ושומר את הכותרות בשפת המקור. עם מפתח, Claude מתרגם כל כותרת לעברית ומוסיף משפט הסבר וקטגוריה.

1. צור מפתח ב־console.anthropic.com (עולה בערך כמה סנטים ליום).
2. בריפו: **Settings ← Secrets and variables ← Actions ← New repository secret**.
3. Name: `ANTHROPIC_API_KEY`, ובשדה Secret מדביקים את המפתח. לעולם אל תכניס אותו לתוך קובץ בריפו.

### בדיקה
לשונית **Actions ← Update AI news ← Run workflow**. אחרי כדקה תראה וי ירוק, ו־`data/news.json` יתעדכן.
מכאן זה רץ לבד כל שעה.

## עריכה שוטפת
- **להוסיף מקור חדשות:** מוסיפים שורה ל־`scripts/feeds.json` עם קישור ה־RSS שלו.
  `all_ai: true` אומר שכל הכתבות במקור רלוונטיות. בלעדיו, הסורק לוקח רק כתבות עם מילים כמו AI, GPT, Claude.
- **להוסיף כלי, טיפ או פרומפט:** עורכים את `data/content.json`, או מבקשים מ־Claude Code לעשות את זה.
- **ידיעה ידנית שתישאר תמיד:** מוסיפים ל־`data/news.json` ידיעה עם `"manual": true`.

## הערות
- נשמרות רק כותרת, משפט הסבר קצר וקישור למקור, לא הכתבה עצמה.
- GitHub מריץ משימות מתוזמנות "בערך" בזמן, ולפעמים באיחור של כמה דקות.
- אם אין פעילות בריפו 60 יום, GitHub משהה את ההרצות המתוזמנות וצריך להפעיל אותן מחדש בלשונית Actions.
- כתובות RSS משתנות מדי פעם. מקור שלא עובד מדולג, ורואים את זה בלוג של ה־Action.
